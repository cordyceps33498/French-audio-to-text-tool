# 隐私说明

## 处理了什么

- 本机正在播放的**系统音频**（loopback），16 kHz 单声道；
- 识别得到的法语文本、翻译得到的中文文本；
- 设备名称/id、窗口位置、字号等本地配置。

## 数据去哪了

- 音频只在内存中经过 VAD → ASR → 翻译，**不落盘、不上传**；
- 识别/翻译文本只输出到控制台或悬浮窗；
- 日志只记录模型路径、耗时、字符数、设备名等运行信息，**不记录识别/翻译正文**；
- 用户配置写在 `%LOCALAPPDATA%\fr-translator\config.yaml`，不写 U 盘；
- 不收集遥测、不做统计、不调用任何分析服务。

## 网络访问

仅在以下情况访问网络：

1. lite 包首次运行下载 faster-whisper + OPUS-MT 模型；
2. asr 包首次运行下载 faster-whisper 模型；
3. 用户显式使用 `--online` 补全缺失模型；
4. 构建时 `scripts/prepare_models.py` 下载模型。

访问目标是 Hugging Face（或用户设置的 `HF_ENDPOINT` 镜像），使用 HTTPS；
`HF_HUB_DISABLE_TELEMETRY=1` 已设置。音频与字幕不会出现在这些请求中。

## 日志与分享

正常日志不含音频/字幕正文，但控制台输出本身包含字幕。若你把控制台重定向到文件，
或使用 `--debug`，请自行脱敏后再分享。错误日志可能包含文件路径、设备名称。

## 删除数据

删除 `%LOCALAPPDATA%\fr-translator\` 即可清除用户配置与回退日志；
删除便携包目录即可清除本地模型与日志。
